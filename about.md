# Fmaill Utilities

A modular collection of Geometry Dash utilities.

## Selective icon unlocker

Configure exact icon IDs by category and apply them as a one-shot action. The mod uses Geometry Dash's own icon-unlock storage and then saves through the normal local save manager.

Supported input examples:

- `12`
- `1, 4, 9`
- `20-30`
- `1, 5, 20-25`

Only valid IDs for Geometry Dash 2.2081 are processed. Invalid entries are ignored and written to the Geode log.
