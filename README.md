# Fmaill Utilities

Mod de Geode para Geometry Dash 2.2081 con un selector visual de iconos.

## Funciones de la versión 0.2.0

- Botón visual en el menú principal usando el cubo y los colores actuales del jugador.
- Vista previa real de cada icono mediante los recursos internos de Geometry Dash.
- Pestañas para cubos, naves, bolas, UFO, wave, robot, spider y swing.
- Selección por clic con resaltado verde.
- Iconos ya obtenidos diferenciados en azul y desactivados.
- Paginación de 18 iconos.
- Selección de todos los iconos visibles en una página.
- Selecciones persistentes mientras no se hayan aplicado.
- Aplicación y guardado en el progreso local normal de Geometry Dash.

## Uso

1. Abre Geometry Dash con Geode y entra al menú principal.
2. Pulsa el botón **ICONOS** de la esquina inferior izquierda.
3. Cambia de categoría y selecciona los iconos que quieras.
4. Pulsa **APLICAR Y GUARDAR**.

El mod solo modifica el guardado local. No altera servidores, rankings, logros ni fechas de obtención.

## Compilación

El workflow incluido compila Windows, macOS, iOS, Android32 y Android64 con Geode SDK 5.7.1.
