# Fmaill Utilities

A Geode mod for Geometry Dash with a clean visual icon selector.

## Visual selector

- Native Geometry Dash-style arrows and buttons.
- One category at a time instead of eight crowded tabs.
- Spacious 4 x 3 grid with twelve larger icon previews per page.
- Dedicated preview panel for the icon currently being viewed.
- Green border and check mark for selected icons.
- Blue border for icons already obtained.
- Persistent selections until they are applied or cleared.
- Local-save unlocking through Geometry Dash's normal `GameManager` save flow.

## Categories

Cube, Ship, Ball, UFO, Wave, Robot, Spider and Swing.

## Build

The project targets Geode `5.7.1` and Geometry Dash `2.2081`. GitHub Actions builds Windows, macOS, iOS, Android32 and Android64.

## Local-only behavior

The mod changes only the normal local save. It does not alter leaderboards, server data, achievements or acquisition dates.
